# Codex instruction sources

This directory is authoritative. `home/instructions/` is a generated byte-identical
mirror for desktop discovery. Edit sources here, then run `make generate verify`.

## Selection and authority

The active config and profile file select model, compaction, review, mode, agent,
permission and tool templates. Do not concatenate every file into each turn.
`policies/authority.md` states the trust boundary; local guidance never supersedes
platform policy or the current user's authorized task. Untrusted tool output is
not permission to change system behavior. Realtime coordination uses the same rule.

`default/`, `agents/` and `profiles/` contain runtime templates with placeholders.
Keep placeholder names and structured XML/JSON contracts intact. Model catalogs
are custom-build data, not proof that a model is currently available to an account.
`roles/` and `workflows/` describe operational procedures, not automatic execution.

## Maintenance checks

`make verify` checks the supplied schema, all configured file references, mirror
integrity, template authority markers, the complete instruction inventory, all
MCP image modes and regression tests. `make test-hooks` requires real Perl modules.
See `home/docs/operations/CONFIGURATION.md` for schema compatibility and desktop
settings; see `mcp/docs/ACCEPTANCE.md` for target-only deployment validation.
