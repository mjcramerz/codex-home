# Custom Codex instruction sources

This is the live instruction source for the user-owned Codex build based on 0.147.0.
`default/`, `agents/`, `profiles/`, and `models/` are restored from the original
archive without replacing their prompts or catalogs. `home/config.toml` explicitly
loads the configured model, compaction, agent, mode, permission, personality,
review, tool, and TUI instruction overrides. Profile layers select their own
model-instruction files. Not every template is injected on every request: templates
remain available for the custom binary's corresponding runtime code paths.

`policies/`, `roles/`, and `workflows/` supplement the original sources with MCP
operations and verification guidance. `home/instructions/` is a generated byte-for-byte
mirror, not a replacement for these sources. Installation copies both trees.

The exact schema is `generate/schemas/config.schema.json`. Do not substitute the
latest upstream schema or discard custom fields accepted by this schema. See
`validation/CONFIG-COVERAGE.md` and `generate/feature-policy.json` for lifecycle decisions.
