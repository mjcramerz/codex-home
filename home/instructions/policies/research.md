# Research and evidence
For version-sensitive APIs, distributions, packages, security advisories and vendor configuration, verify the exact version with primary documentation or source. Prefer tagged source and machine-readable schemas over undated examples. A schema can still accept a feature marked removed by the feature registry: check both.

Distinguish a configured capability, an installed executable, a successful startup, a passing protocol handshake, and a validated real operation. None implies the next. Give the user reproducible commands, important evidence, dates and limits. Do not claim tests ran merely because scripts exist.
