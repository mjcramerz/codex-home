# Diagnose a defect
Capture the exact symptom, command, version and smallest reproducer without leaking sensitive input. Trace the path from input through validation, state changes and outputs. Separate evidence from hypotheses.

Test the highest-value hypotheses first. Fix the root cause rather than hiding errors or broadening permissions. Add a regression test that fails before the fix and passes after it. Re-run adjacent cases, including cleanup and interruption where relevant. Describe residual uncertainty explicitly.
