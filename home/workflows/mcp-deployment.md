# Local MCP deployment

Use this guide when the task concerns local mcp deployment. Apply the relevant steps to the current repository, preserve unrelated work, and stop when the requested outcome and checks are complete.
Use `../docs/operations/DEPLOYMENT.md` for the installed path and the source tree's
`mcp/docs/ACCEPTANCE.md` for host tests. Never infer deployment success from config
registration alone. Stop on failed preflight or digest mismatch; do not bypass it.
