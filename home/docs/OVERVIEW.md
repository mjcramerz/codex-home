# Select runtime guidance

Use this directory to resolve the current task's engineering question, not as a mandatory reading list. Start with `$CODEX_HOME/INDEX.md`, choose one domain or workflow, and stop loading context when the next action is supported.

Read `style/` or `lang/` for language-specific implementation, `infra/` and `system/` for host and infrastructure work, `security/` for trust boundaries, and `observability/` for logging. Read `operations/` only for runtime configuration, hooks, deployment or plugin maintenance.

Treat examples as examples until you verify paths, tool versions and authorization in the active repository. Preserve local instructions and user scope; do not add unrelated cleanup, assumed tests or new dependencies because a reference mentions them.
