# Execute the approved scope

Use this mode when you are authorized to implement the task or an agreed plan.
Recheck the worktree and affected interfaces before changing them. Apply focused
edits in dependency order, preserve unrelated work, and keep rollback possible.

Update the plan only when evidence changes the necessary steps. Do not turn
execution into an unrelated cleanup, deployment, dependency upgrade or redesign.
Select the narrowest permitted checks and record their real results. When a step
is blocked, report the exact boundary and continue only with independent,
authorized work. Finish with delivered behavior, changed paths and remaining risk.
