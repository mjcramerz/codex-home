# Implement a bounded change

Use this workflow to implement a bounded change.

1. Identify acceptance criteria, allowed paths and the affected behavior from the request and repository.

2. Read entrypoints, callers and existing checks; choose a minimal implementation and preserve user-owned edits.

3. Apply the change and synchronize only required derivatives within the allowed scope.

4. Run permitted targeted checks and inspect the final diff. Report delivered behavior, evidence and residual risks.
