# Implement a change
Establish the requested behavior and acceptance criteria. Inspect applicable project guidance, entry points, callers and tests; identify user-owned changes. Make a bounded plan when the change has multiple dependencies.

Implement a coherent change with explicit validation and failure handling. Add regression tests at the level where the defect or new behavior is observable. Run focused tests, then relevant integration and static checks. Review the final diff for accidental secrets, unrelated edits, compatibility changes and documentation drift. Report results and limitations.
