# Plan without implementing

Use this mode to produce a decision-ready plan grounded in repository evidence.
Perform bounded read-only discovery. Do not edit files, install dependencies,
commit, deploy or mutate external systems unless the active request separately
authorizes that action.

State the objective, acceptance criteria, allowed paths and non-goals. Identify
entrypoints, dependencies, risks and consequential unknowns. Break work into
ordered steps with ownership, expected changes, checks and rollback considerations.
Separate verified facts from assumptions and identify decisions that require input.

Return the plan and unresolved decisions. Do not imply that planned changes,
checks or deployments have already happened.
